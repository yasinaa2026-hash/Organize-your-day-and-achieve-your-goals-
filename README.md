# وقتي — نظّم يومك وتحدَّ أصدقاءك

تطبيق عربي متجاوب لتنظيم الدراسة والعمل والمهام الشخصية، مع مؤقّت تركيز وغرف تحدٍّ للأصدقاء.

## المزايا الحالية

- واجهة عربية كاملة باتجاه RTL، مناسبة للكمبيوتر والجوال.
- لوحة يومية تعرض المهام والإنجاز ودقائق التركيز.
- إضافة المهام وتعديلها وحذفها، مع تصنيف وأولوية وموعد وملاحظات.
- مؤقّت تركيز بفترات 15 و25 و45 دقيقة.
- إنشاء غرفة تحدٍّ ومشاركة رمزها.
- قائمة مهام مشتركة ولوحة ترتيب للمشاركين عند تفعيل الاتصال.
- حفظ المهام الشخصية محلياً في المتصفح.

## تشغيل النسخة المحلية

1. افتح رابط المستودع واضغط **Code → Download ZIP**.
2. فك ضغط الملف على جهازك.
3. افتح `index.html` في Chrome أو Edge.
4. ستعمل المهام والمؤقّت والواجهة مباشرة.

في الوضع المحلي، تحفظ المهام على الجهاز نفسه فقط، والغرف محلية للتجربة وليست غرف إنترنت مشتركة بين أجهزة مختلفة.

## تفعيل غرف الأصدقاء أونلاين

تحتاج الغرف الحقيقية إلى مشروع Supabase:

1. أنشئ مشروعاً في [Supabase](https://supabase.com/).
2. من **Authentication → Providers** فعّل **Anonymous Sign-Ins**.
3. افتح **SQL Editor** وشغّل كامل ملف [supabase.sql](supabase.sql).
4. من إعدادات المشروع انسخ **Project URL** والمفتاح العام **Publishable key** أو **anon key** القديم.
5. افتح التطبيق ثم **الإعدادات والربط**، والصق الرابط والمفتاح العام واضغط **حفظ والاتصال**.
6. كرر إعداد الرابط والمفتاح على جهاز صديقك. بعد ذلك يستطيع إنشاء غرفة أو الانضمام باستخدام الرمز.

**تنبيه أمني:** لا تضع مفتاح `service_role` أو أي مفتاح سري في التطبيق أو في GitHub. استخدم المفتاح العام فقط، واترك سياسات RLS في ملف SQL مفعّلة.

## نشر التطبيق على GitHub Pages

1. افتح المستودع في GitHub.
2. ادخل إلى **Settings → Pages**.
3. ضمن **Build and deployment** اجعل **Source** هو **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root))، ثم اضغط **Save**.
5. بعد اكتمال النشر سيظهر رابط الموقع في صفحة Pages.

## الملفات

- `index.html` — واجهة التطبيق.
- `styles.css` — التصميم المتجاوب.
- `app.js` — وظائف المهام والمؤقّت والغرف.
- `supabase.sql` — الجداول والسياسات وإجراءات إنشاء الغرف والانضمام إليها والمزامنة اللحظية.
